ECOMMERCE PROJECT REQUIREMENTS

Users
- A user can register as a Buyer or Vendor and log in/out securely.
- Vendors manage only their own stores and products.
- Buyers browse products, use a shopping cart, checkout and write reviews.

Vendor functions
- Create, view, edit and delete stores.
- Create, view, edit and delete products belonging to their stores.
- Set product name, description, price and stock.

Buyer functions
- Browse products from all stores.
- Add products and quantities to a session cart.
- Remove products from the cart and checkout.
- Leave verified reviews after a purchase or unverified reviews without a purchase.

Security and failure handling
- Django authentication stores passwords securely as hashes.
- Login-required views redirect anonymous users to login.
- Ownership checks stop vendors editing another vendor's data.
- Buyer/vendor role checks stop users accessing the wrong actions.
- Forms validate input and checkout checks stock again before creating an order.
- Database transactions prevent a half-completed checkout.
- Password reset uses Django's time-limited reset token system.
